# 图片转换 SVG 工具 · 使用说明

改造后的工具**不能双击 `index.html` 打开**，必须通过本地 HTTP 服务访问。

## 启动步骤

1. 打开命令行，进入项目目录：

   ```
   cd C:\work\pic2svg
   ```

2. 启动 HTTP 服务：

   ```
   python -m http.server 8000
   ```

3. 浏览器访问：

   ```
   http://localhost:8000/
   ```

   看到工具界面（取点画布、参数面板、生成按钮）即为启动成功。

## 停止服务

在运行服务的命令行窗口按 `Ctrl + C`。

## 端口被占用

若 8000 端口已被占用，换一个端口即可，例如：

```
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 为什么必须走 HTTP 服务

主程序 `assets/app-a1b2c3.js` 通过绝对路径 `/assets/core-a1b2c3.js` 动态加载核心 SVG 生成模块：

- **HTTP 服务**：路径被正确解析，核心模块加载成功，功能完整。
- **双击打开（`file://`）**：浏览器安全策略阻断 module 脚本，工具无法启动，只剩介绍文字。

这正是“另存后拿不到完整功能”的设计原理——另存副本的资源路径失效，核心模块加载不到，与 SVGlo 的机制一致。

## 恢复旧版（可双击使用）

如需回到改造前的单文件版本：

```
copy index.html.bak-20261126-1108 index.html
```

注意：旧版双击即可使用，但另存后功能完整，不具备防另存效果。
