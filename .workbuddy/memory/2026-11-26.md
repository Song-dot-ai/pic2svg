## SVGlo / VTracer 线条与颜色算法研究（续 11-25）
- 拉取 vtracer 1.0 源码核对：流水线 = frontend 分区（color-cluster 连通域+层次合并 / binary 固定或 Bradley–Roth 自适应阈值 / watershed 体积消去分水岭）→ colorfit（区域残留平均色；OKLab 最近色吸附固定/自动调色板；median cut；MergeAdjacent）→ compose（stacked 画家算法 / cutout 共享边界无缝镶嵌）→ 曲线拟合（PathWalker 走线、去锯齿、penalty 化简、保角 4-point 细分、拐点/角位移 splice、最小二乘三次贝塞尔、paper.js 风格 Schneider 二次化简）。
- 结论：VTracer 是"区域分割+边界矢量化"，非边缘检测。对照片连续色调、柔边/半透明、细密纹理、1px 细线小字、噪点、不均匀光照黑白扫描效果差；对纯色块图标/线稿最好。
- 生成压力测试图 `C:/work/pic2svg/vtracer_stress_test.png`（1400x1000，6 面板：渐变球、柔边 alpha、毛发噪点、1px 细线小字、不均匀光照扫描、纯色块对照），用于用户实测。生成脚本 `C:/tmp/gen_vtracer_stress.py`；本地 PIL+numpy 即可，无额度消耗。
